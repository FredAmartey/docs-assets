# Agent guidance

This repository is the shared archive for static documentation and media assets
across public projects.

- Keep current assets tightly coupled to a project's code or documentation in
  that project.
- Put historical, shared or long-lived media here.
- Namespace every batch under `projects/<repo>/` and use a purpose directory
  such as `docs/`, `pull-requests/<number>-<slug>/` or `releases/<version>/`.
- Historical links must use a commit-pinned raw URL, never `main`.
- Give every asset one canonical owner. Do not duplicate the same file in both
  repositories.
- Before moving or deleting an asset, search current documentation and linked
  historical pull requests for inbound references.

Read `README.md` for the full policy.
